laya-guard trial

Paste a shell command a coding agent might run. You get what laya-guard's hook would answer before the command runs: allow, review or block, from regex policies, a safe-command lane and a ~322M local model. One difference from the real hook: there is no project folder here, so the package.json scripts behind npm test and the like aren't checked.

    Privacy: the command is sent to this Space, judged in memory and not logged or stored. Don't paste secrets anyway. Nothing is ever run.
